# Worked routing examples

All scenarios and replies are fictional.

Profile only: “A museum photo and a prompt about getting lost in bookshops.”
Select profile-openers; a specific question about an unexpected find can work. Do not assign a personality type from the photo.

Ongoing chat: both have joked about ranking pastries, and she says “The pistachio one is winning.”
Select conversation-flow. “A strong campaign. What's the runner-up?” builds the existing premise without pretending you tasted it.

Invitation: “She said Sunday might work, but I haven't said if I'm free.”
Select date-invitation and establish the user's availability before drafting acceptance.

Pre-date: “I keep rehearsing jokes and I'm getting tense.”
Select date-presence; prepare a real story and an attentive question, then let the plan stay flexible.

Learning: “I want to understand callbacks.”
Select practice-and-feedback. Demonstrate once, then offer a different scenario and wait for the user's attempt.

Combined: “How did the date go, and what should I text?”
Use connection-review; add date-invitation only if the chosen next step requires arranging another date.
